# Contributing

Please contact Zijie Tang at [tangzj23@mails.tsinghua.edu.cn](mailto:tangzj23@mails.tsinghua.edu.cn)
**before opening any pull request**. Briefly describe the problem, your proposed
change, and how you plan to verify it so we can agree on scope first.

After that discussion, keep changes focused and include the relevant build or
test results. For numerical changes, describe the expected behavior and the
numerical tolerances used in verification. For documentation or skill changes,
check referenced files and runnable commands.

Contributions are submitted under the repository's BSD-3-Clause license.
Preserve existing third-party notices. The contact-first request governs
contributions to this project; it does not add restrictions to the license.
